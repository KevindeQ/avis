# AI Assistant Configuration

This document contains project specific context information for Claude AI to work effectively with this codebase.

## Folder layout
- Folder `apps/` contains the implementations for the specific applications. Each application lives in its own subfolder.
- Folder `data/` contains the runtime application data
- Folder `docs/` contains documentation about the ideation, design and implementation plans for this codebase
- Folder `external/` contains external libraries to be used as support for the implementation of this codebase
- Folder `include/` contains the header files for the general library components of this codebase. Each library component lives in its own subfolder.
- Folder `lib/` contains the source files for the general library components of this codebase. Each library component lives in its own subfolder.
- Folder `tests/` contains the test code for this codebase
- Folder `tools/` contains custom and external tools to help manage specific tasks
